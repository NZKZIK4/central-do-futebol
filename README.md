# Central do Futebol
Projeto acadêmico com 15 páginas usando HTML, CSS e JavaScript.

## Requisitos
- 15 páginas HTML únicas.
- CSS externo em `css/style.css`, CSS interno em páginas selecionadas e CSS inline em páginas alternadas.
- Seletores por tag, classes e IDs.
- Ação JavaScript em todas as páginas.
- APIs em páginas separadas:
  - `resultados.html`: ESPN Scoreboard API.
  - `times.html`: TheSportsDB.
  - `perfil.html`: Random User API.

## Como abrir
Abra `index.html` no navegador. Para testar as APIs, use Live Server no VS Code. As APIs dependem de serviços externos e podem ficar temporariamente indisponíveis.

## Publicar no GitHub Pages
1. Acesse https://github.com/new e crie um repositório público chamado `central-do-futebol`.
2. Extraia o ZIP e envie todos os arquivos e pastas para a raiz do repositório.
3. Abra Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione `main` e `/(root)`, depois clique em Save.
6. Após a publicação, o endereço será `https://SEU-USUARIO.github.io/central-do-futebol/`.
