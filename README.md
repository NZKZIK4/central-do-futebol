# Central do Futebol
Projeto acadêmico com 15 páginas usando HTML, CSS e JavaScript.

## Requisitos
- 15 páginas HTML únicas.
- CSS externo em `css/style.css`, CSS interno em páginas selecionadas e CSS inline em páginas alternadas.
- Seletores por tag, classes e IDs.
- Ação JavaScript em todas as páginas.
- APIs em páginas separadas:
  - `resultados.html`: ESPN Scoreboard API.
  - `times.html`: TheSportsDB.
  - `perfil.html`: Random User API.
